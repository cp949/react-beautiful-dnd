# Installation

[![module formats: cjs and esm](https://img.shields.io/badge/module%20formats-cjs%20and%20esm-green.svg?style=flat)](https://www.npmjs.com/package/@cp949/react-beautiful-dnd)

## General

1. Add the `@cp949/react-beautiful-dnd` package

```bash
# npm
npm install @cp949/react-beautiful-dnd --save

# pnpm
pnpm add @cp949/react-beautiful-dnd

# yarn
yarn add @cp949/react-beautiful-dnd
```

2. Use the package

```js
import { DragDropContext } from '@cp949/react-beautiful-dnd';
```

3. Profit 🕺

## `React` environment

In order to use `@cp949/react-beautiful-dnd` you will probably want to have a `React` environment set up.

- [Add react to a website](https://reactjs.org/docs/add-react-to-a-website.html) - official `React` docs
- [Setup a react environment with `create-react-app`](https://egghead.io/lessons/react-set-up-a-react-environment-with-create-react-app) - from our [free getting started course](https://egghead.io/courses/beautiful-and-accessible-drag-and-drop-with-react-beautiful-dnd) (This is using [react-beautiful-dnd](https://github.com/atlassian/react-beautiful-dnd))

The package publishes ESM and CommonJS builds. `react` and `react-dom` are peer dependencies and must be provided by the application.
